Surfboard Leaderboard

Project writing on physics-informed design for retro arcade aesthetics.

Idea

Build a retro arcade-styled surfboard leaderboard inspired by Hotline Miami, grounded in real physics rather than arbitrary aesthetic choices. The goal was to create an "optical system chain" that simulates how light actually behaves through CRT displays, camera lenses, and VHS tape—making the visual effects feel authentic rather than decorative.

Core philosophy: Physics-informed design—understanding how real systems work and translating that into visual form.

Components

  • Main Leaderboard: Interactive ranked list with hover states, scrolling text, tab switching
  • Thumbnail: "PRESS START" animation for portfolio display, embedded via iframe

Research

Optical System Chain

We established a signal flow that mirrors real hardware:

Light Source → Display Encoding → Hardware (CRT) → Human Vision

Each effect in the chain has a physical basis:

Effect Physics Implementation
Phosphor Glow CRT phosphor excitation creates bloom Layered text-shadow with pulsing spread
Chromatic Aberration Lens dispersion—brighter light = more RGB separation Dual text-shadow (red left, cyan right), intensity tied to glow
Scanlines + Slot Mask CRT shadow mask creates gaps between phosphor triads CSS gradients with multiply blend mode
RGB Phosphor Triads Subpixel color pattern on CRT screens Vertical RGB stripes with screen blend mode
Inverse Intensity Bright bloom fills gaps, making phosphor pattern less visible Phosphor opacity decreases as glow increases
VHS Glitch Magnetic tape tracking errors cause horizontal displacement Deterministic row displacement on timed cycles
Harmonic Sway Organic motion from multi-frequency interference Layered sine waves for translation and rotation

Key Physics Concepts

  • Blend Modes: multiply for shadow/gap effects (subtractive), screen for additive light (phosphors)
  • Hermite Smoothstep: x * x * (3 - 2x) for organic interpolation between glow levels
  • Inverse Intensity: When glow peaks, phosphor overlay opacity drops (bloom fills the gaps)

Iframe Hover Research

Mouse events don't propagate into iframes with pointer-events: none. Solution: postMessage API for parent-to-child communication.

Key Technical Solutions

1. Hover Intensity Without CSS Transition Conflicts

CSS transitions fight with JS-driven animations. Solution: interpolate hover state in JS.

const [hoverIntensity, setHoverIntensity] = useState(0);

const animate = (timestamp) => {
  setHoverIntensity(prev => {
    const target = hovered ? 1 : 0;
    const speed = 0.08;
    if (Math.abs(prev - target) < 0.01) return target;
    return prev + (target - prev) * speed;
  });
};

2. Iframe Hover via postMessage

Parent page sends hover state, thumbnail listens and updates accordingly.

// Parent
link.addEventListener('mouseenter', () => {
  iframe.contentWindow.postMessage({ type: 'hover', state: true }, '*');
});

// Iframe
window.addEventListener('message', (event) => {
  if (event.data?.type === 'hover') setHovered(event.data.state);
});

Learnings

Technical

  1. CSS transitions don't mix with JS animations—they try to smooth every frame change, which dampens or kills the animation. Use JS interpolation instead.
  2. Iframes are isolated documents—mouse events don't cross the boundary, especially with pointer-events: none. postMessage is the clean solution.
  3. Blend modes matter—multiply subtracts (shadows/gaps), screen adds (light/phosphors). Using the wrong one breaks the physics.
  4. Performance: Move static data and style objects outside React components to prevent recreation on every render.

Design Philosophy

  1. Physics-informed design creates authenticity—effects grounded in real optical/hardware behavior feel "right" even if viewers can't articulate why.
  2. The optical chain is a system—each effect influences the next. Glow causes CA. Glow fills phosphor gaps. Everything is connected.
  3. Inverse relationships are powerful—bright glow reducing phosphor visibility mimics real CRT bloom physics and creates visual coherence.
